# data/

성과 측정 데이터. 코드가 아니라 **운영 기록**이다.

## performance.csv

월 1회, 네이버 크리에이터 어드바이저에서 옮겨 적는다.
`npm run perf-report` 가 이걸 읽어서 "어떤 글·어떤 소제목 형태가 먹혔나"를 집계하고,
상위 성과 글은 다음 초안 생성 시 few-shot 예시로 프롬프트에 들어간다.

이 파일이 비어 있으면 시스템은 지금까지처럼 매번 같은 품질의 글을 뽑는다.
**학습 루프의 입력이 여기 하나뿐이다.**

### 채우는 법

1. 크리에이터 어드바이저 접속
2. 내 블로그 통계 → 게시글별 조회수 / 평균 사용시간
3. AI 브리핑 인용 → 글별 인용수 (2026-01부터 누적)
4. 아래 형식으로 한 줄씩 추가 (같은 글을 여러 시점에 적어도 된다 — 최신 행을 쓴다)

```
slug,measured_on,views,avg_seconds,ai_citations,likes,comments,inflow_keywords
2026/08/2026-08-08-실온이유식-...,2026-09-30,1240,73,3,45,8,실온이유식;중기이유식 실온보관
```

`measured_on` 은 조회한 날짜다. 누적 지표라 언제 봤는지가 중요하다.
