# 네이버 홈피드 노출 전략

> 출처: 오리나 홈피드 강의 무료 전자책 108P (2024~2025).
> 기술 파트 — 네이버 "발견/탐색 프로덕트" 팀 공식 발표 자료 인용 (AfterSearch Retriever, Click2Click Retriever, AiRScout, DCN/MDE Ranker, TransAct).
> 실전 파트 — 저자 A/B 테스트 경험 기반.

**Why:** 네이버가 2023.8 홈피드 도입 후 검색→추천 중심으로 전환 중. 홈피드 DAU +600%, 클릭 수 +800%. 블로그 유입의 중심이 검색에서 홈피드로 이동.

**How to apply:** 글 작성 시 **"이 글은 상위노출용인가, 홈피드용인가"를 먼저 결정**하고 스타일을 분리.

---

## 1. 홈피드 AI 추천 구조

| 모듈 | 역할 |
|---|---|
| **AfterSearch Retriever** | 사용자가 하루 이내 검색한 이력과 연관 문서 추천 |
| **Click2Click Retriever** | 사용자가 클릭한 문서와 유사한 문서를 임베딩 벡터 기반 추천 |
| **AiRScout** | LLM으로 콘텐츠 주제 자동 태깅 → 약 760개 주제 분류 |
| **DCN Ranker** | 제목+이미지로 클릭 확률 예측 |
| **MDE Ranker** | 체류시간+만족도까지 예측해 순위 결정 |
| **TransAct** | 실시간 Transformer로 사용자 최신 관심사 즉시 반영 |
| **Calibration** | KL Divergence로 추천 편향 방지, 콘텐츠 다양성 확보 |

### 핵심: 키워드가 아니라 "문맥, 경험, 감성, 독창성"
- 홈피드 AI는 **본문 전체를 읽고** 주제+문맥+제목 연관성까지 분석.
- 키워드 최적화된 정보형 글 → 홈피드 반응 없음 (저자 직접 테스트 확인).
- 경험 중심 감성형 글 → 홈피드에 바로 노출됨.

---

## 2. 상위노출 vs 홈피드 — 글쓰기 전략 분리

| 항목 | 상위노출용 | 홈피드용 |
|---|---|---|
| 제목 | "OO 추천, OO 후기 (가격/위치 정리)" | "OO 갔는데... 친구들이 미쳤대요ㅋㅋ 후기 갑니다" |
| 본문 스타일 | 정보형, 단답형, 정리형 | **이야기형, 감성형, 일기형** |
| 핵심 평가 지표 | 키워드 밀도, 구조화 | **체류시간, CTR, 댓글/공감** |
| 수명 | 순위 밀리면 끝 | 가치 있으면 1~2년 후에도 추천 |

## 3. 홈피드용 글 작성 규칙

### 제목
- 억지 후킹/낚시성 절대 X (`충격! 대박! 놓치면 손해!`)
- 본문을 예고하는 **영리한 티저** — 호기심 자극하되 진정성 있게
- **제목과 본문이 어긋나면 AI가 감지 → 노출 탈락**
- 예시:
  - "이 식당 가면 꼭 '이거' 시키세요"
  - "다이소가서 구매안하면 평생 후회하는 주방 꿀템"

### 첫 3줄 = 스크롤 유도력
- **제목보다 본문 첫 단락이 더 중요**
- 클릭 후 첫 몇 줄 읽다가 이탈하면 → AI가 감지 → 다시 추천 안 함
- 첫 3줄에 공감, 질문, 반전, 감성, 진짜 경험 담기
- 본인만의 말투/감성/관점/리듬을 확실하게 보여주기

### 본문 구성
- 딱딱한 "1. 메뉴 2. 가격 3. 총평" 나열 → 탈락
- **사람 말투처럼 일기 형식의 자연스러운 흐름**
- 문단 구성과 리듬감 중요

### 발행 빈도
- 홈피드 초반: **하루 1포스팅 루틴** (다양한 주제 시도하며 '홈피드 감' 익히기)
- 안정기: 매주 최소 2~3회 이상
- 안정 노출까지 **최소 3개월** (저자 경험: 10개월 무반응 후 11개월차 돌파)

### 핵심 KPI
1. **CTR** (클릭률) — 노출됐을 때 클릭 여부
2. **체류시간** — 완독률 높을수록 알고리즘이 더 자주 노출
3. **재방문 유도** — 다른 글도 읽게끔 → 지속적 홈피드 노출

### 홈피드 적합 주제
- ✅ 맛집, 리빙, **육아**, 패션, 경제, 방송연예, 스포츠
- ❌ 게임, 책, 지식, 웹툰, 반려동물 (홈피드 조회수 낮음)

## 4. 우리 블로그 적용 방향

- 상위노출 글(정보형 키워드 SEO)과 홈피드 글(감성형 이야기)을 **포지셔닝 분리하여 병행**
- "지나의 휴일" 카테고리(육아, 리빙, 맛집)는 홈피드 적합 주제와 일치
- **체험단/리뷰 글도 "정보 나열"이 아닌 "경험 이야기" 흐름으로 전환**
