# 사진 보정 톤 — 밝고 화사한 따뜻한 육아 감성톤

> 인스타 [@haedal_home](https://www.instagram.com/haedal_home/) 참고. 밝고 화사하면서 따뜻한 톤 + 대비 낮춰 부드러운 느낌.

---

## 기본 보정 수치

iPhone 편집 기준, 스케일 -100 ~ +100.

| 항목 | 값 |
|---|---|
| 노출 (Exposure) | +15 ~ +20 |
| 휘도 (Brilliance) | +30 ~ +40 |
| 하이라이트 (Highlights) | -20 ~ -30 |
| 그림자 (Shadows) | +30 ~ +40 |
| 대비 (Contrast) | -20 ~ -30 |
| 밝기 (Brightness) | +10 |
| 따뜻함 (Warmth) | +5 ~ +15 |
| 색조 (Tint) | +10 ~ +15 |

---

## 적용 방법

- 새 글 작성 시 사진 보정 단계에서 위 수치를 sharp 스크립트로 일괄 적용 (`scripts/upload-images.ts` 등 이미지 파이프라인 참고).
- 사용자가 수치 변경 요청 시 이 문서 업데이트.
