# 자연어로 쓰는 법 — 지나님용 사용설명서

> 이 레포는 명령어를 외울 필요가 없습니다. **사진만 한 폴더에 모아두고 Claude에게 말하면** 됩니다.
> 이 문서는 (1) 지나님이 무엇을 말하면 되는지, (2) Claude가 그때 무엇을 해야 하는지를 정의합니다.
> Claude는 이 문서를 매 세션 읽고 그대로 따릅니다.

---

## 0. 지나님이 직접 하는 일은 딱 2개

1. **사진을 한 폴더에 모으기** (Finder에서 새 폴더 만들고 드래그)
2. **Claude에게 말하기**

나머지(폴더 구조, 파일 양식, 키워드 조사, 초안 생성, 검사, 커밋, 배포)는 전부 Claude가 합니다.
`npm run ...` 을 지나님이 칠 일은 없습니다.

---

## 1. 새 글 쓰기 — 이렇게 말하면 됩니다

### 가장 짧은 형태

```
클레 실온이유식 협찬 후기 쓸 거야. 사진은 ~/Desktop/클레이유식 에 있어.
```

이렇게만 말해도 Claude가 나머지를 **물어봅니다.** 미리 정리해 올 필요 없습니다.

### 사진 위치를 알려주는 3가지 방법

| 상황 | 이렇게 말하면 됨 |
|---|---|
| 폴더를 만들어 뒀다 | "사진은 `~/Desktop/클레이유식` 에 있어" |
| 아이폰에서 방금 에어드롭했다 | "방금 다운로드에 에어드롭했어" (최근 24시간 이미지를 찾습니다) |
| Finder에서 폴더를 드래그하고 싶다 | 터미널에 폴더를 드래그하면 경로가 붙여넣어집니다 |

> 영상(MP4/MOV)은 같은 폴더에 있어도 됩니다. Claude가 **복사하지 않고 목록만 알려줍니다.**
> 네이버에 올릴 때 지나님이 직접 넣으시면 되고, 본문에는 "여기 영상" 표시가 남습니다.

### 한 번에 다 말하고 싶다면

아래를 말/글로 주시면 질문 없이 바로 진행합니다. **순서도 형식도 상관없습니다. 생각나는 대로 쓰셔도 Claude가 정리합니다.**

```
클레 실온이유식 협찬 후기.
사진은 ~/Desktop/클레이유식.

8월 20일부터 5주 먹였어. 하루 두 번.
냉동실이 꽉 차서 자리가 없었는데 조리원 동기가 실온 되는 거 있다고 알려줬어.
전에 쓰던 냉동 이유식은 데우는 데 오래 걸려서 그 사이에 봄이가 울었는데,
이건 바로 데워지니까 안 울고 먹어. 양도 더 먹고.
근데 유리병이라 외출할 때 무겁고 깨질까 봐 신경 쓰여.
꿀팁은 뚜껑 열기 전에 흔들면 안 된다는 거.
외출용으로는 계속 살 것 같은데 집에서만 먹일 거면 굳이 싶어.
```

## 2. Claude가 물어볼 것 (미리 몰라도 됨)

빠진 게 있으면 **한 번에 모아서** 물어봅니다. 하나씩 여러 번 묻지 않습니다.

### 반드시 확인하는 것 (법적/계약 문제)

| 항목 | 왜 필요한가 |
|---|---|
| **협찬인가 직접 산 건가** | 고지 문구 유무가 달라집니다. 틀리면 법적 문제 |
| **체험단 가이드가 있나** | 있으면 다른 모든 룰보다 우선합니다 (계약 사항) |

구매 형태는 넷 중 하나입니다. 말로 하시면 Claude가 골라 넣습니다.

- 내 돈 주고 삼 → `self-purchased`
- 원고료 + 제품 받음 → `sponsored`
- 제품만 무상으로 받음 (가이드 없음) → `gifted`
- 음식점·시설 체험단 → `service-experience`

### 있으면 글이 확 좋아지는 것

| 항목 | 예시 |
|---|---|
| 언제부터 얼마나 | "8월 20일부터 5주, 하루 두 번" |
| 사기 전 고민 | "냉동실 자리가 없었음" |
| 계기 | "조리원 동기가 알려줌" |
| 봄이(또는 나니·스리) 반응 — 전/후 | "전엔 기다리다 울었는데 지금은 안 욺" |
| **아쉬운 점 / 실패담** | "유리병이라 무겁고 깨질까 봐 신경 쓰임" |
| 꿀팁 | "뚜껑 열기 전에 흔들면 안 됨" |
| 비교 대상 | "전에 쓰던 ○○ 냉동 이유식보다 빠름" |
| 재구매 의사 | "외출용으로만 계속" |

> **아쉬운 점이 가장 중요합니다.**
> 장점만 있는 글은 AI가 쓴 글과 구분되지 않고, 2026 네이버는 AI 스팸을 실시간으로 걸러냅니다.
> 단점 한 줄이 글 전체의 신뢰도를 만듭니다. 협찬 글도 마찬가지입니다 — 가이드가 금지하지 않는 한 넣습니다.

### 절대 안 들어가는 것 (물어보지도 않습니다)

가격 · 수량 · 사이즈(mm) · 모유수유 표현 · 본문 협찬 언급.
말씀하셔도 본문에서 빠집니다. (`AGENTS.md` Hard Rule)

## 3. 그 밖에 자주 쓸 말

| 이렇게 말하면 | Claude가 하는 일 |
|---|---|
| "실온이유식 키워드 좀 봐줘" | 검색량·문서수·기회점수 뽑아서 표로 보여주고, 소제목용 질문 6개 제안 |
| "이번 달 성과 정리했어" + 숫자 붙여넣기 | `data/performance.csv`에 기록하고 집계 리포트 |
| "갱신할 글 뭐 있어?" | 오래됐는데 유입 있는 글 순위 |
| "이 글 검사해줘" | lint 돌리고 문제만 요약 |
| "세 번째 문단 좀 더 짧게" | 해당 부분 수정 → 검사 → 커밋 |
| "네이버에 올릴게" | `/naver/<슬러그>` 링크와 사진·영상 삽입 위치 안내 |
| "이번 주 몇 편 썼지?" | 발행 리듬 확인 (하루 2편·주 2~4편 상한) |

## 4. Claude 실행 규약 (Claude가 지킬 것)

> 이 절은 Claude용입니다. 지나님은 읽지 않으셔도 됩니다.

### 새 글 요청을 받으면

1. **사진 위치 확보** → `npm run intake -- --from <경로> --title "<제목>"`
   (에어드롭 언급이면 `--from-recent --hours 24`)
   결과에서 사진 장수와 영상 목록을 지나님께 보고한다.
2. **빠진 정보를 한 번에 묻는다.** 여러 번 나눠 묻지 않는다.
   구매 형태와 체험단 가이드 유무는 **항상** 확인한다 (추측 금지).
3. **`notes.txt` 를 Claude가 작성한다.** 지나님 발화를 `docs/writing-input-guide.md` 의
   7항목 양식으로 재배치한다. 없는 항목은 비워 둔다 — **지어내지 않는다.**
   `purchase.txt`, `topic.txt` 도 같이 채운다.
4. **키워드**: `npm run keywords -- --seed "<메인후보>" --out <input폴더>`
   API 키가 없으면 건너뛰고 그 사실을 알린다. 지나님이 키워드를 직접 주셨으면 그대로 쓴다.
5. **초안**: `npm run generate-draft -- --input <폴더> --category <카테고리>`
   카테고리는 대화에서 추론하되 애매하면 묻는다. `pet` 은 나니·스리 글에만.
6. **검사**: `npm run lint:posts -- <파일>` → 에러는 반드시 고치고, 경고는 판단해서 고친다.
   `alt-too-short` 는 사진을 다시 보고 상황·맥락까지 넣어 다시 쓴다.
7. **보고**: 글 제목 / 분량 / 소제목 목록 / 남은 경고 / `/naver/<슬러그>` 링크를 알린다.
   본문 전체를 터미널에 쏟지 않는다. 지나님은 사이트나 네이버 업로드 페이지에서 읽는다.
8. **커밋 + 푸시** (`AGENTS.md` 룰). 지나님이 따로 요청하지 않아도 진행한다.

### 항상 지킬 것

- **초안은 초안이다.** 지나님만 아는 디테일이 빠져 있을 수 있으니, 보고할 때
  "확인이 필요한 부분"을 함께 짚는다 (사진 캡션의 추측 부분 등).
- **사진 캡션을 추측으로 단정하지 않는다.** 확실하지 않으면 그 사진을 지목해 묻는다.
- **발행 리듬** 상한(하루 2편·주 2~4편)을 넘길 상황이면 먼저 알린다.
- **`brand` / `product` / `certifications`** 는 확실할 때만 채운다. 정식 제품명을 추측해
  넣으면 구조화 데이터가 틀린 정보를 퍼뜨린다.
- **frontmatter `tldr` / `faq` 는 본문과 글자 그대로 일치**해야 한다. 불일치는 검색엔진 제재 위험.

### 하지 말 것

- 지나님께 `npm run ...` 을 치라고 안내하지 않는다. Claude가 실행한다.
- 입력 파일 양식을 지나님께 설명하고 작성을 요구하지 않는다. Claude가 쓴다.
- 질문을 여러 턴에 걸쳐 조금씩 하지 않는다.
